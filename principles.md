# Project Principles

1. Keep the code simple and easy to understand.
2. Write clear logic and avoid unnecessary complexity.
3. Favor readable solutions over clever shortcuts.
4. Document important decisions when needed.
5. Respect the standards and review process.
6. Make changes with purpose and consistency.
7. Communicate clearly with the team.
8. Prioritize correctness, safety, and maintainability.
9. Test changes before relying on them.
10. Improve the project continuously.
