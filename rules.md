# Project Rules

1. Write readable and maintainable code.
2. Use clear, descriptive names for variables and functions.
3. Keep functions small and focused on one responsibility.
4. Add comments only when necessary to explain intent.
5. Handle errors explicitly and avoid unsafe patterns.
6. Validate input and guard against edge cases.
7. Keep commits focused and meaningful.
8. Review code carefully before merging.
9. Respect team members and maintain a professional workflow.
10. Follow the repository standards at all times.
