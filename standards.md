# Coding Standards

1. Use descriptive names for variables, functions, and files.
2. Keep functions small — under 50 lines, single responsibility.
3. Add type hints on all public functions.
4. Add docstrings/Javadoc on all public functions and classes.
5. No bare `except:` — catch specific exceptions.
6. No magic numbers — use named constants.
7. Use `is None` instead of `== None` (Python).
8. Use `const`/`let` instead of `var` (JavaScript).
9. Use `===` / `!==` instead of `==` / `!=` (JavaScript).
10. Follow Conventional Commits — one logical change per commit.
